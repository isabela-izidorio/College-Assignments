# College Assignments | Trabalhos Acadêmicos

Collection of academic assignments developed throughout college, documenting practical exercises, projects, and technical studies.

Coleção de trabalhos acadêmicos desenvolvidos ao longo da graduação, reunindo exercícios práticos, projetos e estudos técnicos.

> Academic repository | Repositório acadêmico

## Organization | Organização

Each subject is identified by its course code and name, and contains its respective assignments.

Cada disciplina é identificada pelo código e nome da matéria e contém suas respectivas atividades.

```
├── [CODE]subject-name/
│   ├── activity-01/
│   ├── activity-02/
│   └── activity-03/
│
├── [CODE]subject-name/
│   ├── activity-01/
│   └── activity-02/
│
└── [CODE]subject-name/
    └── activity-01/
```
