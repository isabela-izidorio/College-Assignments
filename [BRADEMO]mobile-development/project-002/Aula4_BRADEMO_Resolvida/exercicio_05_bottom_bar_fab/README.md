# Exercício 5 — BottomAppBar e FAB

Botão flutuante centralizado com recorte na barra inferior, navegação entre abas e opções que aparecem ao tocar no FAB.

## Executar

```bash
flutter pub get
flutter run
```

Se os diretórios nativos ainda não existirem, execute `../bootstrap_platforms.sh` a partir da pasta raiz do pacote da atividade (em uma máquina com Flutter instalado).
