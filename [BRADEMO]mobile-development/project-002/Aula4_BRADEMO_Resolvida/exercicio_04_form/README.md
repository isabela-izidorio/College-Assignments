# Exercício 4 — Form e SnackBar

Formulário de nome, telefone e data de nascimento; ao enviar, os dados são exibidos em um SnackBar.

## Executar

```bash
flutter pub get
flutter run
```

Se os diretórios nativos ainda não existirem, execute `../bootstrap_platforms.sh` a partir da pasta raiz do pacote da atividade (em uma máquina com Flutter instalado).
