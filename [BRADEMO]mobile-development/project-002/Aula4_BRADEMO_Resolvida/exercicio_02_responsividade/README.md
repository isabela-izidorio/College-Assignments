# Exercício 2 — Responsividade

Layout que alterna entre coluna em telas estreitas e duas áreas em telas largas usando LayoutBuilder.

## Executar

```bash
flutter pub get
flutter run
```

Se os diretórios nativos ainda não existirem, execute `../bootstrap_platforms.sh` a partir da pasta raiz do pacote da atividade (em uma máquina com Flutter instalado).
